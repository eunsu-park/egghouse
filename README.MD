이 레포지터리는 제 개인 프로젝트에서 사용하는 공통 기능을 모아두기 위해 만든 것입니다. 일부 내용은 제가 직접 작성했으며, 일부는 AI가 검수하거나 AI의 도움을 받아 작성되었습니다.

This repository was created to collect common utilities used across my personal projects. Some content was written by me, some was reviewed by AI, and some was created with the help of AI.
